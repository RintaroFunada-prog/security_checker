# 生成AI 利用リスクチェック（ローカルPoC）

添付の「生成AI利用ガイドライン v1.5（2026年5月1日版）」をもとに、利用計画の確認ポイントを表示するStreamlitアプリです。入力内容は保存しません。生成AIや外部サービスへの送信も行いません。

## ローカルで起動（Windows PowerShell）

```powershell
cd "<このフォルダーのパス>"
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

ブラウザーで表示されたURL（通常は http://localhost:8501 ）を開きます。終了はPowerShellで `Ctrl+C` です。

## 判定の考え方

- 個人情報の入力、許可のない顧客情報、保護のない環境での社外秘等の入力、指定された著作物の社外利用を「利用禁止に該当する可能性」として表示します。
- 承認が必要な情報利用、推奨外サービス、AIエージェント、危険操作、意思決定や社外提供を含む場合は「高リスク・事前確認が必要」と表示します。
- それ以外も正式な承認ではなく、ガイドラインに沿った目安です。顧客ルールや契約、クラウドサービス利用申請など別途確認が必要な場合があります。
- 回答はアプリのセッション内で判定に使い、データベースやファイルに記録しません。実際の機密情報・個人情報・顧客情報は入力しないでください。

## Azureに公開するとき

Azure環境が整うまではローカルで画面と判定ルールを調整できます。App Serviceへの公開時はLinux App Serviceの起動コマンドを次のように設定します。

```text
python -m streamlit run app.py --server.port 8000 --server.address 0.0.0.0 --server.headless true
```

社内利用者へURLを案内する前に、App ServiceのMicrosoft Entra認証を必須にし、エンタープライズアプリで割り当て必須を有効化して、承認されたユーザーまたはグループだけを割り当ててください。設定と対象外アカウントでの拒否確認が完了するまでは公開案内をしないでください。

## 変更時の注意

ガイドライン改定、社内ルール変更、ITPM部等からの運用指示があった場合は、`evaluate()` の判定ロジックと画面の説明を合わせて更新してください。現在の判定ロジックはルールベースであり、会社による公式認定を受けた判定システムではありません。
